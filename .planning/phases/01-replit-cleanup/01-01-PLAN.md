# Plan: 01-01-PLAN.md

## Goal
Remove all Replit-specific dependencies, plugins, and configurations from the AgriRent monorepo to prepare for vendor-neutral deployment (Vercel).

## Context
The project was initialized with several `@replit/` scoped packages that provide dev-time tools (cartographer, dev-banner, etc.) specific to the Replit environment. These are not needed for Vercel deployment and should be stripped to clean the codebase.

## Must-Haves
- [ ] No `@replit/` packages in `pnpm-workspace.yaml`.
- [ ] No `@replit/` dependencies in any `package.json`.
- [ ] No Replit plugin imports or usage in `vite.config.ts` files.
- [ ] `replit.md` and related config files deleted.

## Steps

### 1. Remove Catalog Definitions
- [ ] Edit `pnpm-workspace.yaml` to remove Replit packages from the `catalog` and `minimumReleaseAgeExclude`.

### 2. Remove Dependencies from Packages
- [ ] Edit `artifacts/faas-platform/package.json` to remove Replit dependencies.
- [ ] Edit `artifacts/mockup-sandbox/package.json` to remove Replit dependencies.

### 3. Clean Vite Configurations
- [ ] Edit `artifacts/faas-platform/vite.config.ts` to remove Replit plugin usage.
- [ ] Edit `artifacts/mockup-sandbox/vite.config.ts` to remove Replit plugin usage.

### 4. Delete Replit-specific Files
- [ ] Delete `replit.md` (if exists in root).
- [ ] Check for and delete `.replit` or `replit.nix` (if exist).

### 5. Verification

- [ ] Run `pnpm run typecheck` to ensure no broken imports remain.
